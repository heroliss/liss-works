# 玻璃海运行快照与验收范围

作品站的海岛绘制展示与 `play/glass-atoll/` 在线体验为两条不同实现：前者使用轻量伪3D绘制，后者是独立实时场景。首页、详情、紧凑半透明控制界面和项目讨论入口已经交付。

在线体验由 `scripts/vendor-glass-atoll.py` 从工作区同级原工程只读导出，`glass-atoll-provenance.json` 记录每个输入及产物的 SHA-256，构建时再次核对。原图、原始录音、原生显示器工具、诊断与工作区历史不随静态网站发布。

当前快照保留完整图形与星表数据，以已有低画质预设为托管默认，用户可调高。星表采用无损压缩传输，HTTP、网络或解码失败时回退原始二进制。`npm run test:atoll-transfer` 直接执行快照加载器验证正常路径与失败恢复，不以另一套加载实现替代。

## 明确保留的工程边界

- 55ms物理步长截断在严重低帧时会使模拟慢于墙钟。统一子步推进涉及水体、物体、烟花、天体和声音事件，未在本次网站发布中重写。
- 高分辨率完整烟尘双发的最近隔离压力结果约22.59FPS；原约1FPS场景尚未相同条件长期复测闭合，不能保证任意设备60FPS。
- 普通多发受光技术检查通过，极端12发近场的空间精度尚未达标。
- 生产混音和调度已有技术验证，声音自然度及整体主观体验仍需实际试听。
- 夜间数据（约53MB）已改为按需加载：白昼首帧前本地无压缩测量约9.8MB（改前约63MB）。夜间预设有等待提示，后续时间改动会取消等待，加载失败时提示并继续显示不含星点的夜色；数据完整保留，不删星，也不降低纹理精度。慢速网络与Pages压缩传输下的实际耗时尚未测量；若在加载完成前直接拖到夜间，星点会在数据到达后才出现。

这些边界属于独立实时体验的下一轮性能与质感工作，不代表作品主页伪3D小岛尚未完成。工作区完整证据位于 `glass-atoll/verification/performance-20261101/`、`audio-light-lifecycle/` 与 `release-20261105/`；历史报告不替代当前设备实测。
